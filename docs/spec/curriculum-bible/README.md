# Project Atlas — Curriculum & Islamic Education Bible v1.0

**Purpose:** A repository-ready, original curriculum design brief for ages 2 through Grade 6. This is a planning and content-authoring framework, **not** an official NAMC curriculum, Singapore Ministry of Education syllabus, or verified transcription of any religious text.

## Educational pillars
1. Montessori: practical life, sensorial, language, mathematics, culture/cosmic education, peace and independence.
2. Singapore mathematics: concrete–pictorial–abstract (CPA), number bonds, place value, bar models, problem solving and metacognition.
3. STEM/robotics: unplugged logic, design-build-test, mechanical systems, sensors, programming, safe AI literacy.
4. Islamic studies: Ahl al-Sunnah wa al-Jama'ah with the requested Ash'ari/Maturidi and Shaykh Abdullah al-Harari framing, with explicit scholarly verification of attributed texts.
