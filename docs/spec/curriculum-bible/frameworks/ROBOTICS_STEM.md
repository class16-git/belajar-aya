# Robotics, coding and engineering

| Stage | Skills | Sample original challenge | Safety |
|---|---|---|---|
| 2–3 | cause/effect, sorting, sequence | arrange three picture steps for washing hands | no small parts, adult-led |
| 3–4 | directions, paths | floor-arrow treasure path | no screen required |
| 4–5 | algorithms, debugging | instruct adult robot to reach a mat | no unsupervised powered toys |
| K | loops/repetition | repeat 3 moves and predict result | supervise robotics kits |
| G1 | sequencing, events | programmable floor robot navigates grid | no personal-data capture |
| G2 | loops, mechanics | block-code robot through maze | age-rated kits |
| G3 | conditions, sensors | obstacle-avoidance model | low voltage |
| G4 | circuits, data | light-sensitive signal model | low voltage only |
| G5 | microcontrollers, testing | plant-moisture monitor | no mains electricity |
| G6 | systems, algorithms, ethics | service-oriented robotics capstone | review physical safety |

Use engineering design cycle: Ask → Imagine → Plan → Create → Test → Improve → Communicate. Assessment includes documentation, debugging, collaboration, safety and reflection—not merely whether robot works. Hardware is optional; provide unplugged equivalents. No soldering, mains electricity or lithium battery handling for children without qualified adult supervision.
