# Singapore Math implementation framework

Use CPA and mathematical reasoning as the core, not speed drills.

## Progression
- Concrete: objects, counters, ten-frames, place-value blocks.
- Pictorial: dots, number bonds, part-whole diagrams, bar models.
- Abstract: equations, symbols and written explanations.
- Transfer: unfamiliar word problems, multiple representations, explain why.

## Problem solving
Understand → plan representation → solve → check → explain. Provide a hint ladder: manipulatives → diagram → targeted prompt → worked explanation (after attempt). Never reveal answer keys to child clients.

## Example original unit: Grade 1 number bonds to 10
Objective: compose/decompose 10 with physical counters; show 7 + 3 as a part-whole model; explain inverse relationship. Diagnostic: 3 original items. Practice: 6 varied items. Transfer: story with toys. Exit: two independent items. Offline: ten small objects sorted into two groups.

## Grade scope checkpoints
G1 numbers to 100, operations, measurement; G2 to 1,000, equal groups; G3 multiplication/division and fractions; G4 multi-step fractions/decimals; G5 percentages and ratio foundations; G6 ratio, algebra readiness, data and geometry. Validate exact school-level sequencing against a legally obtained, edition-specific Singapore syllabus or licensed series.
