# Reading and Literacy Scope & Sequence

## Five strands (independent progress)
1. Oral language and listening comprehension: naming → retell → inference → critical listening.
2. Phonological awareness and decoding: rhyme → syllables → phonemes → sound-symbol → decoding and fluency.
3. Vocabulary and knowledge building: concrete nouns → categories → morphology → domain-specific terms.
4. Comprehension: sequence → main idea → inference → compare sources → evidence-based critique.
5. Reading identity and habits: shared reading → choice → self-direction → independent reading with healthy limits.

## Montessori connection
Use three-period lessons for vocabulary, sandpaper letters and movable alphabet where developmentally suitable; integrate story baskets, object cards, real-world observation and oral narration. Digital experiences support rather than replace physical work.

## Assessment policy
Do not infer decoding ability from listening comprehension. Track independent performance, hints, parent assistance and confidence separately. A child can read above/below grade without changing grade. Never label children as deficient from one failed item. Use reviewed passages only; never expose answer keys to the client.

## Content coverage expectation
Each stage requires: learning objectives, prerequisites, approved book candidates, 2–3 parent-guided activities, optional digital activity, comprehension rubric, accessibility check, license evidence, reviewer and publication status. No lesson is considered complete based on metadata alone.
