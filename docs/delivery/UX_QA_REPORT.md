## Heuristic checks
| Spec requirement | Result |
|---|---|
| Calm neutral palette, tactile material colours, minimal chrome | ✅ paper/linen background, bead colours, no celebratory animation |
| Child header: objective, parent-controlled exit | ✅ goal line + "Grown-ups" PIN gate (audio prompts: P1 backlog) |
| Large concrete/pictorial model left/top, one question, 2–4 options or number entry, "I need help", "Check" | ✅ |
| Gentle, precise feedback; wrong → representation + another try | ✅ misconception-specific copy, ten-frame highlight, eliminated options |
| Never autoplay endless problems; clear finish after short set | ✅ 3–10 items (parent setting), explicit Next/Finish |
| Toddler card: objective, prep time, safe materials, steps, adult wording, cues, clean-up, repeat another day | ✅ |
| Touch targets ≥ 44 px (child) | ✅ automated check on every child state; most child controls 56–64 px |
| Child body text 18–24 px | ✅ 20 px mobile / 22 px tablet+ |
| WCAG AA contrast; correctness not by colour alone | ✅ axe 0 violations; ✓/○ icons and text accompany colour |
| Animations < 300 ms, reduced motion honoured | ✅ 200 ms; OS setting and per-child toggle |
| All strings via locale keys; EN/ID | ✅ parity test; content bilingual |
| Avoid "Wrong!", "Too slow!", rank, fake praise | ✅ test-enforced |
